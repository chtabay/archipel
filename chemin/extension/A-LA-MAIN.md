# À essayer à la main, avec tes comptes

Ce que les essais automatiques ne peuvent pas faire : les vrais sites. Avec des contenus inventés, cocher ce qui arrive
dans la page du jour (sous la frise, d’un clic sur l’icône), et noter ce qui manque ou ce qui est de trop.

## Gmail

- [ ] Un nouveau courriel, envoyé à la souris : le corps arrive ; l’objet et les destinataires n’arrivent pas.
- [ ] Le même, envoyé par Ctrl+Entrée.
- [ ] Une réponse avec la citation repliée (« … ») : la citation n’arrive pas.
- [ ] Une réponse tapée à l’intérieur de la citation : rien n’arrive (c’est la règle : ce qui est dans une citation est à d’autres).
- [ ] Une signature active : elle n’arrive pas.
- [ ] Une suggestion de Smart Compose acceptée avec Tab : arrive-t-elle, ou non ?
- [ ] Un brouillon rouvert plus tard, une phrase ajoutée : seul l’ajout arrive.
- [ ] La boîte de recherche de Gmail : rien n’arrive.

## Outlook sur le web

- [ ] Un nouveau courriel, à la souris, puis par Ctrl+Entrée.
- [ ] Une réponse glissée entre deux paragraphes cités : le paragraphe cité du milieu n’arrive pas.
- [ ] Une réponse où l’historique cité se charge après l’ouverture : il n’arrive pas.

## Google

- [ ] Depuis l’accueil, trois mots, Entrée : la recherche arrive.
- [ ] Depuis la page de résultats, une autre recherche, Entrée : elle arrive aussi (lue dans l’adresse).
- [ ] Une suggestion choisie aux flèches ou à la souris : c’est la recherche faite qui arrive.
- [ ] Les recherches font leurs tuiles à elles, à part des courriels.
- [ ] Dans Gmail, Docs ou Agenda : rien de ce qui n’est pas un écrit n’arrive.

## ChatGPT et Claude

- [ ] Un message envoyé par Entrée, puis un autre par le bouton.
- [ ] Deux messages de suite qui commencent par les mêmes mots.
- [ ] Un message collé depuis une page web : le collage n’arrive pas.

## Ailleurs

- [ ] WhatsApp Web : Entrée, le bouton, une réponse à un message.
- [ ] Slack : un message dans un canal dont le nom contient « code » ou « secu » (c’était un trou ; il doit arriver).
- [ ] LinkedIn : un message, un commentaire.
- [ ] N’importe où : changer d’onglet au milieu d’une phrase, revenir, finir : un seul bloc.
- [ ] Firefox : charger `dist/manifest.json` dans `about:debugging` ; si l’icône porte « ! », redonner l’accès aux sites
  depuis l’accord ; puis Gmail par Ctrl+Entrée.
